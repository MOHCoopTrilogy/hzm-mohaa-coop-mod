// OURS (names the engine never addresses):
//   hzm_loadhint_bg    dark strip along the bottom, full width
//   hzm_loadhint_line  amber hairline on the strip's top edge

//                      ui/loadhints.txt; an old exe shows the one hint coop_defaults.cfg seeds.
//                      Strip + hint are shown while ui_loadHintsOn (the exe publishes it; seeded 1).
//                      The rect starts right of the medal, so centred text can never run under it.
//   hzm_loadmedal      the medal: scripts/coop_loadmorph.shader hzmLoadMedalMorph, the looping old<->new
//                      logo (gen_loadscreen_medal.py --morph; static hzmLoadMedal = the revert). Its rect is
//                      48 x 256/230 = 53.43 about the same centre: the morph art has a mip-safe margin
//                      (bug-3059); revert the rect to 12 420 48 48 with the shader. scalecvar keeps it
//                      ROUND on every aspect: vidHeight/480 x ui_loadIconScale on BOTH axes - position
//                      included, so that cvar must stay 1. It only has to EXIST when this file is
//                      parsed (Cvar_Find), which is why coop_defaults.cfg seeds it for old exes.
// Draw order is file order, and this file is included AFTER each menu's own art: ours first, so the
// Continue button draws over the strip.
// ================================================================================================
